# SilverCare

中文 | [English](./README.en.md)

Silver Care Mini Program — 面向老年人的医院陪诊服务微信小程序（前端原型，无后端）。

## 运行

1. 用微信开发者工具打开本仓库根目录（`miniprogramRoot` 为 `./`）
2. 若 `miniprogram_npm/` 缺失或更新了组件库，执行「工具 → 构建 npm」
3. 编译即可预览，所有页面无需登录直接访问

## 目录速览

| 目录 | 说明 |
| --- | --- |
| `pages/index` | 首页：品牌问候 + 四个服务入口 |
| `pages/book` | 预约：日期 / 时段 / 服务类型 |
| `pages/orders` | 订单列表与详情 |
| `pages/report` | 服务报告 |
| `pages/urgent` | 紧急求助（模拟客服） |
| `pages/customer` | 个人中心 |
| `assets/` | 图片资源（首页横幅） |
| `reference/` | 设计稿参考图 |
