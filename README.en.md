# SilverCare

[中文](./README.md) | English

Silver Care Mini Program — a WeChat mini program for **hospital companion services for the elderly** (frontend prototype, no backend).

## Getting Started

1. Open the repository root in WeChat DevTools (`miniprogramRoot` is `./`)
2. If `miniprogram_npm/` is missing or the component library was updated, run **Tools → Build npm**
3. Compile to preview — all pages are accessible without login

## Directory Overview

| Directory | Description |
| --- | --- |
| `pages/index` | Home: brand greeting + four service entries |
| `pages/book` | Booking: date / time slot / service type |
| `pages/orders` | Order list and details |
| `pages/report` | Service report |
| `pages/urgent` | Urgent help (simulated customer service) |
| `pages/customer` | Profile |
| `assets/` | Image assets (home banner) |
| `reference/` | Design mockup references |
